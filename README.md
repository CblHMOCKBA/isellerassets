# Библиотека моделей АйСеллера

Общая библиотека для всех роликов. Модели копируются в проект ролика, а не берутся по ссылке. Каждая новая модель остаётся здесь.

| Папка | Что лежит |
|---|---|
| characters/ | персонажи: курьер-маскот, коты, крестьяне, монах, учёный |
| devices/ | обобщённая техника без логотипов: iPhone, MacBook, Dyson, PS5, робот-пылесос |
| props/ | предметы: коробки, картошка, костёр, кастрюля, весы |
| environments/ | сцены: двор с многоэтажкой, квартира, деревня, Горбушка, карта Москвы |
| ui/ | терминал симулятора, HUD-плашки, финальная карточка, шрифты |
| audio/ | звук запуска симулятора, переходы, фоновый синтез |
| styles/ | эталон стиля: палитра, шейдеры, кадры-референсы |
| _inbox/ | свежие модели до проверки |

Правила:
- Формат .glb. Имя: `<что>_<вариант>_v1.glb`, например `courier_orange_v1.glb`.
- Каждая модель записывается строкой в `catalog.csv`: файл, что это, откуда (Meshy, Kenney, Quaternius, кодом), лицензия, в каких роликах использована.
- Kenney, Quaternius и KayKit — только CC0, файл лицензии кладём рядом.
- Логотипов брендов и реальных людей в моделях нет.
- Ключи (MESHY_API_KEY) только в `.env` в папке АйСеллер, сюда не кладём.

## Общий репозиторий

Эта папка — приватный репозиторий github.com/CblHMOCKBA/isellerassets (Габриель и Илья). Модели (.glb, текстуры, звук) идут через Git LFS.
Как работать: `git pull` перед началом, новые модели кладём в нужную папку, строку в `catalog.csv`, затем `git add . && git commit -m "добавил <что>" && git push`.

Первый раз на компьютере: `brew install git-lfs && git lfs install`, затем `git clone https://github.com/CblHMOCKBA/isellerassets.git`.

Рядом лежат `scenarios/` (ТЗ рубрики «Симулятор миров») и `styles/simulyator-stil-referens.png` (референс трёх стилей).
