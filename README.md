# Библиотека моделей АйСеллера

Общая библиотека для всех роликов. Модели копируются в проект ролика, а не берутся по ссылке. Каждая новая модель остаётся здесь.

| Папка | Что лежит |
|---|---|
| characters/ | персонажи: курьер-маскот, коты, крестьяне, монах, учёный |
| devices/ | обобщённая техника без логотипов: iPhone, MacBook, Dyson, PS5, робот-пылесос |
| props/ | предметы: коробки, картошка, костёр, кастрюля, весы |
| environments/ | сцены: двор с многоэтажкой, квартира, деревня, Горбушка, карта Москвы |
| ui/ | терминал симулятора, HUD-плашки, финальная карточка, шрифты |
| audio/ | звук запуска симулятора, переходы, фоновый синтез |
| styles/ | эталон стиля: палитра, шейдеры, кадры-референсы |
| _inbox/ | свежие модели до проверки |

Правила:
- Формат .glb. Имя: `<что>_<вариант>_v1.glb`, например `courier_orange_v1.glb`.
- Каждая модель записывается строкой в `catalog.csv`: файл, что это, откуда (Meshy, Kenney, Quaternius, кодом), лицензия, в каких роликах использована.
- Kenney, Quaternius и KayKit — только CC0, файл лицензии кладём рядом.
- Логотипов брендов и реальных людей в моделях нет.
- Ключи (MESHY_API_KEY) только в `.env` в папке АйСеллер, сюда не кладём.

## Общий репозиторий

Эта папка — приватный репозиторий github.com/CblHMOCKBA/isellerassets (Габриель и Илья). Модели (.glb, текстуры, звук) идут через Git LFS.
Как работать: `git pull` перед началом, новые модели кладём в нужную папку, строку в `catalog.csv`, затем `git add . && git commit -m "добавил <что>" && git push`.

Первый раз на компьютере: `brew install git-lfs && git lfs install`, затем `git clone https://github.com/CblHMOCKBA/isellerassets.git`.

Рядом лежат `scenarios/` (ТЗ рубрики «Симулятор миров») и `styles/simulyator-stil-referens.png` (референс трёх стилей).

## Модели из 2.5D-роликов (kit25d), 11.11.2026

189 моделей и персонажей из роликов «Антилия», «Брат Апельсин» и движка kit25d. Лежат в подпапках `kit25d/`:

| Папка | Что | Сколько |
|---|---|---|
| environments/kit25d/ | локации: дом Антилия, улица в Мумбаи, разрез дома, магазин АйСеллер, ТЦ, карта Индии, деревня, бар и улица в Нью-Йорке, квартира, китайская улица, аэропорт, неоновая улица, гостиная, Луна | 33 |
| props/kit25d/ | предметы: вертолёт, кран, монеты, ценник, рикша, мебель, ёлка, рояль, самолёт, чемодан, фонарики, трава, камни | 90 |
| devices/kit25d/ | техника без логотипов: смартфон, раскладной телефон, ноутбуки, роутер, сканер, старые телефоны, факс | 9 |
| characters/kit25d/ | 3D-куклы (11 штук) | 11 |
| characters/kit25d-cast/ | рисованные персонажи PNG с прозрачным фоном, листы толпы | 46 |

Как пользоваться:
- Рядом с каждой .glb лежит превью .jpg с тем же именем. Описание каждой модели — в `catalog.csv`.
- Масштаб: 1 единица = 1 метр. Предметы, техника и куклы стоят центром низа в точке 0,0,0. Локации — в координатах ролика.
- Сетка сжата без потери вида (KHR_mesh_quantization). Открывается в three.js, Blender и Godot 4 без плагинов. `india_map_island_v1.glb` хранит пальмы инстансами (EXT_mesh_gpu_instancing).
- Свет, небо, туман и свечения в .glb не входят, в сцене нужен свой свет. Окна, экраны и гирлянды светятся через emissive. Металл без карты окружения темнее, чем в ролике: в three.js задать `scene.environment`.
- Рисованные персонажи — PNG 576×1088, рост персонажа 1024 px, земля на строке 1056.
- Реальных людей и чужих логотипов нет: семья Амбани, Мэтт и Ли не выгружались, надписи брендов закрашены. Все 748 текстур проверены.
- В ролик на kit25d: положить файл как `library/models/<id>/model.glb` и вызвать `loadModels(['<id>'])`.
- Выгрузка повторяется скриптом `kit25d/tools/glb_export.mjs` (лежит в проекте Claude: `assets/modeli-rilsov/_export/`).
